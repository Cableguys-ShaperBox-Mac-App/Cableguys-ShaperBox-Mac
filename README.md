## 📊 Overview  

Cableguys ShaperBox is a versatile multi-FX platform built for producers who want total control over movement, modulation, and detailed sound sculpting. The suite revolves around Cableguys’ signature editable LFO curves, allowing users to craft custom modulation shapes that drive every effect. From subtle enhancement to extreme rhythmic transformations, ShaperBox gives you a modern modular workflow that adapts to any creative situation.

Each module—known as a *Shaper*—handles a specific aspect of audio manipulation, such as timing, volume, filtering, stereo width, distortion, liquid-style modulation, or transient shaping. These Shapers can be stacked, reordered, mixed, and synced with pinpoint accuracy, making it possible to build everything from pumping sidechain effects to evolving stereo textures or experimental rhythmic motions.

ShaperBox is especially powerful for producers working in electronic, pop, hip-hop, cinematic, and sound design fields. With its audio and MIDI-trigger options, the plugin can react dynamically to incoming signals, allowing envelopes to fire exactly when a drum hits or a synth note is played. Dynamic visual feedback gives a clear view of what every modulation curve is doing at every moment.

Whether you want clean utility processing or wild creative sound design, ShaperBox offers a workflow that blends precision with playful experimentation. Instead of relying on multiple plugins, producers can consolidate complex signal chains inside a single, highly customizable environment.

## 🚀 Key Features  

| Feature | Description |
|---------|-------------|
| 🧩 Stackable Shapers | Combine multiple modules like Time, Volume, Filter, Pan, Width, Crush, and more. |
| ✍️ Customizable LFO Curves | Draw, edit, and animate modulation shapes with complete flexibility. |
| 🎹 MIDI & Audio Trigger Modes | Trigger effects via transient detection or MIDI note input. |
| 🎵 Rhythmic Sculpting | Build gates, ducks, stutters, sync-based effects, and pumping patterns. |
| 🎧 Stereo Manipulation | Create widening, narrowing, motion, and mid/side shaping with precision. |
| 🔥 Creative Distortion Tools | Modulate waveshaping, bit reduction, and harmonic behaviors dynamically. |
| 🕒 Time-Based FX | Achieve reverses, tape stops, stutters, and time warping via TimeShaper. |
| 📈 Visual Interaction | Real-time display of modulation curves and how they affect your audio. |
